Verify your download

Each release page lists the file sizes and checksums that were published with the build. Compare them before you run an installer: 

# Windows
Get-FileHash .\windows.zip -Algorithm SHA256

# Linux and macOS
sha256sum linux.tar.gz

The checksums live on the release page itself, not in this template, so this page can never show a hash that belongs to a different build.
